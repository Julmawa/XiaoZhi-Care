# Contributing

Contributions are welcome.

## Before opening an Issue

Do not attach:

- Flash dumps;
- NVS dumps;
- Wi-Fi credentials;
- private keys or tokens;
- personal health information;
- names, addresses or phone numbers from a real Care installation.

Use synthetic data when reproducing Care behavior.

## Pull requests

Please:

1. Keep Care changes modular.
2. Avoid unnecessary modifications to upstream XiaoZhi core files.
3. Document new behavior.
4. Include a test or reproducible validation procedure.
5. Preserve privacy and rollback behavior.
6. Follow the upstream XiaoZhi coding conventions where applicable.

## Medication workflows

Changes affecting medication-related behavior require especially clear tests and must not introduce guessing or medical decision-making.
