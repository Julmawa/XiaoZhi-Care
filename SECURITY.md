# Security policy

## Supported version

The current alpha release is the only actively maintained XiaoZhi Care version.

## Reporting a vulnerability

Do not publish credentials, Flash dumps, personal data or security-sensitive reproduction material in a public Issue.

When the GitHub repository is created, enable **Private vulnerability reporting / GitHub Security Advisories** and use that channel for security-sensitive reports.

If a vulnerability affects upstream XiaoZhi rather than XiaoZhi Care, report it through the upstream project's preferred security process.
