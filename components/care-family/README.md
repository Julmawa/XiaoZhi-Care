# care-family

Componente de relaciones familiares de XiaoZhi Care.

Guarda vínculos entre personas ya registradas, por ejemplo:

- Ale es hija de Yolita.
- Aldana es esposa de Ale.
- Martina es hija de Ale y Aldana.

La fuente de verdad de las personas sigue siendo `care-core`.
Este componente guarda solamente relaciones entre IDs de persona.
