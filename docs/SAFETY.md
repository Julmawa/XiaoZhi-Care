# Safety and medication-related use

XiaoZhi Care is an assistive software project. It is **not a medical device**.

It must not be used as the sole source of truth for medication decisions.

## The medication feature is intended to

- remind the user which pillbox compartment is relevant;
- orient the conversation using the current day/time;
- help verify a past unconfirmed compartment visually;
- share confirmation history between conversational and reminder flows.

## It is not intended to

- diagnose;
- prescribe;
- change medication;
- calculate doses;
- replace a physician, pharmacist, caregiver or family member;
- resolve uncertainty about a medication by guessing.

Medication schedules and pillbox contents should be configured and checked by a responsible person.

If the stored schedule conflicts with professional instructions, follow the professional instructions and correct the stored data.
