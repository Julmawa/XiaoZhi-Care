# Release assets

Do not commit generated firmware ZIPs or private Flash backups here.

Binary installer packages should be attached to a GitHub Release.

For `v0.3.2-alpha`, publish:

- `XiaoZhi_Care_0.3.2-alpha_Installer_bread-compact-wifi.zip`
- its SHA-256 checksum
- release notes
- supported hardware/profile information

Never attach a user Flash backup.
