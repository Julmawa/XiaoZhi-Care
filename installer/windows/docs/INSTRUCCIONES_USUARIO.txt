COMPATIBILITY / COMPATIBILIDAD / COMPATIBILIDADE

- 16 MB Flash
- 8 MB PSRAM

INSTALL / INSTALAR
1. Extract the complete ZIP / Descomprima el ZIP completo / Extraia o ZIP completo.
2. Connect the ESP32-S3 by USB / Conecte la ESP32-S3 por USB.
3. Run INSTALAR_XIAOZHI_CARE.bat.
4. Choose or accept the language / Elija o acepte el idioma / Escolha ou aceite o idioma.
5. Follow the checks shown on screen.
6. A full 16 MB backup is created before any installation write.
7. Confirm installation only after all checks pass.

SAFETY / SEGURIDAD / SEGURANCA
- The installer does NOT run erase-flash.
- El instalador NO ejecuta erase-flash.
- O instalador NAO executa erase-flash.
- XiaoZhi NVS is preserved / La NVS de XiaoZhi se conserva / A NVS do XiaoZhi e preservada.
- Firmware files are checked with SHA-256.
- Secure Boot and Flash Encryption must be disabled.
- If compatibility cannot be proven, installation is cancelled before flashing.
